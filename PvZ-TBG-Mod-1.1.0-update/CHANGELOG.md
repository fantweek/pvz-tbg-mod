## [1.1.0] — 2026-11-21
Настройки «в обе стороны», сборки привязаны к профилям игры, меню стало нагляднее. Каждый параметр можно и усложнить, и упростить; всё применяется во всех режимах, где есть соответствующая механика (приключение, выживание, мини-игры, конвейерные уровни).
### Добавлено
- **Настройка по типам** (раскрывающийся блок внизу вкладок «Растения» и «Зомби»): для каждого из 48 растений отдельно здоровье, скорость атаки, скорость перезарядки семени и цена; для каждого из 33 типов зомби — скорость, здоровье тела и броня (проценты от обычного). Значения перемножаются с общими настройками; строка «Всем» задаёт весь столбец.
- **Растения:** стартовое солнце уровня (только для нового уровня, продолженная сохранёнка не меняется), свой потолок солнца (ниже или выше 9990; солнце не растёт выше потолка, а то, что уже есть сверх него, не отбирается), цена всех растений в процентах (дешевле и дороже), скорость пережёвывания чомпера и скорость взвода мины (множители в обе стороны, мгновенный режим главнее).
- **Зомби:** ожидание первой волны (дольше или короче).
- **Конвейер:** пауза подачи, выбор семени из набора «случайно / по кругу», «без повторов подряд».
- **Вкладка «Сборки TBG»:**
  - первая кнопка — сброс всех настроек до обычной игры (без сборки и заморозки);
  - **лесенка сложностей** Легко → Нормально − → Сложно → Безумно → Невозможно → Кошмар (каждая следующая строже предыдущей, тест проверяет монотонность по всем параметрам);
  - **профиль у каждой сборки:** игрок с точным именем (`TBG Easy`, `TBG Hard`, …, особые — `TBG Sandbox`, `TBG Fast`, …). Когда в игре выбран новый игрок с таким именем, мод сам начинает собирать прогресс и замораживает меню; выйти можно, пройдя приключение, выбрав другого игрока или нажав «Сбросить». Кнопка «Начать» убрана;
  - вкладка показывает имя выбранного игрока и имя профиля каждой сборки; разделы «Сложности» и «Особые сборки».
- **Видно, что включено:** значок с числом включённых настроек на вкладках, суммарное число в заголовке, строка «Включено на этой вкладке: N» и кнопка **«Сбросить вкладку»** (возвращает только эту вкладку к оригинальным значениям; инструменты, суммы выдачи и «работа в фоне» не трогает).
- Скриншоты новых вкладок; профили и конфигурации хранят новые таблицы (старые файлы настроек читаются, недостающие значения = 100%).
### Изменено
- Вкладка «Игра» стала **«Инструменты»** (только разовые действия: разблокировки, запуск уровня, выдача денег/растений/достижений). Ценность монет, скорость игры и работа в фоне переехали на вкладку «Уровень», блок «Игра: монеты, скорость, система».
- Сборки «Усложнённое» и «Лёгкая прогулка» убраны — их заменила лесенка сложностей. Их прохождения в старом `runs.ini` отбрасываются; остальные переносятся по id (файлы старого формата читаются).
- Прогресс в `runs.ini` хранится по id сборки (`build_<id>=…`), а не по номеру: порядок сборок можно менять без потери прогресса.
- Выключенные флажки и поля имеют заметную рамку; ручка ползунков темнее, чтобы число на ней читалось.
### Исправлено
- Подписи «Тело» и «Броня» в блоке здоровья зомби выровнены по одной колонке.
- Кнопка «Применить к посаженным» в блоке «Здоровье и защита» обрезалась по ширине окна (теперь на своей строке, «Применить к уже посаженным»).
### Не проверено на настоящей игре
- Всё новое протестировано на подделанной памяти игры (376 проверок, в том числе случайные настройки под UBSan), но не на самой игре: стартовое солнце, ожидание первой волны, пауза конвейера и такты чомпера/мины опираются на уже используемые адреса, но их поведение нужно проверить в бою.
- Мод видит только имя выбранного игрока (списка профилей игры у него нет), поэтому «профиль существует» значит «выбран игрок с этим именем». Чтение имени (std::string по смещению 0 профиля) проверено только на подделанной памяти.
- Цена растений: игра списывает обычную цену, мод возвращает или доплачивает разницу, поэтому для посадки по цене ниже обычной всё равно нужна полная обычная цена (проверку делает игра).

## [1.0.0] — 2026-11-15
Первый публичный выпуск. Проект получил название **PvZ TBG Mod**, иконку и оформление для GitHub. Номера 1–3.7 ниже — внутренние версии разработки до публикации; 1.0.0 включает всё из них.
### Добавлено
- Иконка и сведения о версии в `pvzmod.dll` и `PvZModLauncher.exe`, иконка в трее и у окна меню, версия в заголовке меню.
- Единый скрипт сборки `scripts/build.py` (Windows / Linux / macOS), автосборка и тесты в GitHub Actions.
- Скриншоты меню для README (`tools/screenshots`): настоящий код меню отрисовывается на Linux без запуска игры.
### Интерфейс
- Длинные подсказки в меню переносятся по строкам, а не обрезаются справа; баннер заморозки тоже.
- «Перезарядка семян — свой множитель»: ползунок вынесен на отдельную строку, раньше кнопки ×0.5…×3 не помещались в окно.
### Исправлено (по результатам аудита кода)
- Зомби, убитые кнопкой «Убить всех» / F7, больше не приносят солнце.
- Деньги, выданные кнопкой в бою, не умножаются на «Цену монет».
- На конвейерных и безсолнечных уровнях мод не списывает солнце и не отменяет посадку; случайная замена семян там не срабатывает.
- Значения NaN/inf, номер растения вне списка и записи о несуществующих сборках в файлах настроек больше не ломают мод.
- Числа в настройках сохраняются без потери точности; `last.ini` сохраняется и при скрытом меню; запись файлов идёт через временный файл.
- «Сбросить» / «Начать» на разных сборках не путают друг друга; маска растений для слотов читается в момент команды.
- Отложенная выдача случайного набора не залипает.
- Загрузка конфигурации берёт значения по умолчанию для полей, которых нет в файле.
- Длинные сообщения статус-строки не обрезаются (и не режутся посреди символа UTF-8).
- Лаунчер: повторные попытки подключения (до 4) вместо одной; не освобождает память, которую ещё читает игра, при таймауте.

## Предыстория: внутренние версии до публикации

### Внутренняя 3.6
- **Премиум без носителя:** проверка солнца вернулась (флаг «лёгкой посадки» игры отключал и проверку, и списание); посадка отменяется, если солнца не хватает.
- Состав волн пересобирается/возвращается к оригиналу сам при смене настроек посреди уровня (раньше «случайные зомби» залипали).
- Вкладка **Конвейер** (в «Уровне»): скорость подачи семян и свой набор растений на ленте.

### Внутренняя 3.5
- Исправлена ошибка ImGui («Must call EndChild() and not End()») — карточки меню больше не нарушают баланс стека при прокрутке.

### Внутренние 3.1–3.4
- Автозапуск: лаунчер в трее следит за игрой и подключает мод сам (`--watch`, `--autostart on|off`), поддержка параметров запуска Steam (`"лаунчер" %command%`).
- Запуск игры через Steam, защита от второго экземпляра («Unable to load Steam.dll»).
- Корректный поиск окна игры (по классу и заголовку, а не первое попавшееся окно `MainWindow`).

### Внутренняя 3.0
- Ценность монет, горячие клавиши F6 / F7 / F8, время в боях под заморозкой, ещё 3 сборки (всего 11).

### Внутренняя 2.0
- Ценность одного солнца, скорость солнца с неба и солнечных растений, солнце с зомби.
- Выдача достижений и растений, перестройка вкладок.
- «Сборки» с процентом прохождения, заморозкой настроек и привязкой к игроку.

### Внутренняя версия 1
- Первая версия: меню по Tab (Растения / Зомби / Уровень / Игра / Профили), конфигурации, разблокировки, случайные уровни и наборы.

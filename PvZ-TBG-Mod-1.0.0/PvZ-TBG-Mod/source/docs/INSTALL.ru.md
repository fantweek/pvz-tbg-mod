# Установка PvZ TBG Mod

Нужна **Steam-версия Plants vs. Zombies GOTY 1.2.0.1096 (английская)**. На другой версии мод распознаёт чужой exe и **не включается** (ничего не ломает).

## 1. Файлы

В архиве: `pvzmod.dll` и `PvZModLauncher.exe` — это и нужно копировать в игру; папка `source/` — исходный код проекта (для разработчиков, в игру её копировать не нужно).

1. Закройте игру. Steam → Plants vs. Zombies GOTY → Управление → Просмотреть локальные файлы.
2. Скопируйте туда `pvzmod.dll` и `PvZModLauncher.exe` (рядом с `PlantsVsZombies.exe`).

## 2. Способ запуска (выберите один)

**А. Через параметры запуска Steam — рекомендуется.** Steam → правый клик по игре → Свойства → Общие → Параметры запуска:

```
"C:\полный\путь\к\PvZModLauncher.exe" %command%
```

Путь можно взять в Проводнике: Shift + правый клик по файлу → «Копировать как путь» (кавычки уже будут).
Теперь обычная кнопка **«Играть»** запускает игру вместе с модом.

**Б. Автозапуск.** Запустите `PvZModLauncher.exe` один раз и ответьте «Да» на вопрос про автоматическое подключение. Лаунчер останется в трее
(правый клик по значку — меню) и будет сам подключать мод при любом запуске игры. Вручную: `PvZModLauncher.exe --watch`,
`PvZModLauncher.exe --autostart on` / `off` (запуск вместе с Windows).

**В. Вручную.** Запустите игру, дождитесь главного меню, затем запустите `PvZModLauncher.exe` — он только подключит мод.

В игре нажмите **Tab**. Настройки применяются сразу.

## 3. Где лежат данные

Папка `PvZMod` рядом с `pvzmod.dll`:

| Файл | Что это |
|---|---|
| `last.ini` | текущие настройки (подхватываются при следующем запуске) |
| `profiles\*.ini` | сохранённые конфигурации |
| `runs.ini` | прохождения готовых сборок |
| `backup\userdata_first_run` | копия ваших сохранений игры, сделанная при первом запуске мода |

## 4. Если что-то не работает

- **«Unable to load Steam.dll».** Эту ошибку показывает сама игра при втором экземпляре или запуске вне Steam. Закройте все `PlantsVsZombies.exe` и `PvZModLauncher.exe`
  (Диспетчер задач, значок в трее), запустите игру кнопкой «Играть», не запускайте Steam и лаунчер от имени администратора (оба должны работать одинаково).
- **«Окно игры не найдено» / «не появилось».** Дождитесь главного меню игры и запустите лаунчер снова. В сообщении перечислены найденные окна класса `MainWindow`.
- **Меню не видно поверх игры.** Переключите игру в оконный режим (в полноэкранном эксклюзивном режиме окна поверх иногда не показываются).
- **«Часть патчей отключена» в строке состояния.** Байты игры не совпали с ожидаемыми — вероятно, другая сборка или мод-загрузчик. Остальные функции работают.
- **Антивирус ругается на лаунчер.** Он подключает DLL к процессу игры; исходники открыты, собрать можно самому (см. README).
- **Другие моды** (например, загрузчик с `modconfig.toml`) могут конфликтовать. Проверьте целостность файлов игры в Steam и уберите чужие `.dll`.

## 5. Удаление

Удалите `pvzmod.dll`, `PvZModLauncher.exe` и папку `PvZMod`; очистите параметры запуска в Steam. Если включали автозапуск — правый клик по значку в трее →
снять «Запускаться вместе с Windows» → «Выход» (или `PvZModLauncher.exe --autostart off`). Резервная копия сохранений лежит в `PvZMod\backup`
(можно вернуть в папку `userdata` игры).

# Участие в разработке

Спасибо за интерес к PvZ TBG Mod! Подробное устройство — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

1. Установите `pip install ziglang pillow`.
2. Внесите изменения в `src/`, добавьте проверку в `tests/test_logic.cpp`.
3. `python scripts/build.py all` должен пройти без ошибок и предупреждений.
4. Опишите изменение в `CHANGELOG.md` (раздел «Не выпущено» сверху) и, если меняется поведение, в `docs/FEATURES.ru.md`.
5. Откройте pull request. Если правите адреса игры — укажите, как проверяли (сборка игры, отладчик).

Правила проекта:
- Мод рассчитан только на **одиночную игру** и на одну сборку exe (Steam 1.2.0.1096); патчи кода всегда сверяют байты перед записью.
- В репозиторий нельзя добавлять файлы игры (exe, графику, звуки) и результаты их декомпиляции целиком.
- Названия и тексты меню — на русском; комментарии в коде — на русском или английском.

Новая версия: изменить `src/version.h`, дополнить `CHANGELOG.md`, поставить тег `vX.Y.Z` — CI соберёт архив и опубликует релиз.
